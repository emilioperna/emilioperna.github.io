Informativa sulla privacy

Ultimo aggiornamento: 21 ottobre 2026

In breve: TubeIQ funziona solo sul tuo computer. Legge in sola lettura i dati del canale YouTube che colleghi, li mostra a te e non li invia a nessun server di TubeIQ, perché un server di TubeIQ non esiste.

1. Chi siamo

TubeIQ è un software personale installato ed eseguito sul computer del suo utilizzatore. Non esiste un servizio online di TubeIQ né un database centrale. Titolare del trattamento è la persona che installa e usa il software. Contatto: emiliopernaprivato@gmail.com.

2. Quali dati accede

Quando colleghi il tuo account Google, TubeIQ chiede questi permessi in sola lettura:

  • YouTube Data API (youtube.readonly): informazioni pubbliche e di base del canale e dei video (titoli, statistiche, date).
  • YouTube Analytics API (yt-analytics.readonly): statistiche del canale come visualizzazioni, tempo di visualizzazione, retention, fonti di traffico, termini di ricerca e dati demografici aggregati.
  • Solo se lo scegli: entrate stimate (yt-analytics-monetary.readonly).

TubeIQ non può pubblicare, modificare o cancellare nulla sul tuo canale o sul tuo account Google.

3. Come usa i dati

I dati servono solo a mostrarti statistiche, grafici e suggerimenti dentro l'applicazione sul tuo computer. Non sono usati per pubblicità, profilazione o addestramento di modelli di intelligenza artificiale, e non sono venduti.

4. Dove sono conservati

  • Il token di accesso Google è salvato nel portachiavi del sistema operativo (Gestione credenziali di Windows o Portachiavi di macOS) sul tuo computer.
  • Le statistiche scaricate e la cache sono salvate in file locali nella cartella dati di TubeIQ sul tuo computer.
  • Nessun dato viene inviato a server di TubeIQ.

5. Condivisione con terzi

TubeIQ non condivide i dati con terzi. Fanno eccezione le azioni che scegli tu: per esempio, se colleghi un assistente AI (come ChatGPT o Claude) e gli chiedi un'analisi, le informazioni necessarie alla risposta vengono inviate a quel servizio con il tuo account e secondo le sue condizioni.

6. Conservazione e cancellazione

Puoi cancellare tutti i dati in qualsiasi momento eliminando la cartella dati di TubeIQ o disinstallando il software. Per revocare l'accesso di TubeIQ al tuo account Google usa il pulsante "Scollega" nell'app oppure la pagina Autorizzazioni dell'account Google. I dati ottenuti dalle API di YouTube vengono aggiornati o eliminati secondo le norme per gli sviluppatori dei servizi API di YouTube.

7. Norme di Google e YouTube

TubeIQ usa i servizi API di YouTube. Usandolo accetti i Termini di servizio di YouTube. Il trattamento dei dati da parte di Google è regolato dalle Norme sulla privacy di Google.

L'uso e il trasferimento ad altre applicazioni delle informazioni ricevute dalle API di Google da parte di TubeIQ rispettano le Norme relative ai dati utente dei servizi API di Google, inclusi i requisiti di Uso limitato.

8. Modifiche

Eventuali modifiche a questa informativa saranno pubblicate su questa pagina con una nuova data di aggiornamento.

English summary

TubeIQ is a personal app that runs only on its user's computer. With your consent it reads, read-only, your YouTube channel data (YouTube Data API and YouTube Analytics API) to show you statistics. Data and tokens are stored locally (tokens in the operating system's credential store); nothing is sent to TubeIQ servers, because none exist. Data is not sold, not shared, and not used for advertising or AI training. You can revoke access at any time at myaccount.google.com/permissions. TubeIQ's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. By using TubeIQ you agree to the YouTube Terms of Service; see also the Google Privacy Policy. Contact: emiliopernaprivato@gmail.com.
